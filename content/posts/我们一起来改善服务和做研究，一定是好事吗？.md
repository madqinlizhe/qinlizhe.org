# "我们一起来改善服务和做研究"，一定是好事吗？

作者/公众号：亲历者Qinlizhe
发布时间：2026-11-10
原文链接：https://doi.org/10.1007/s11266-018-9971-4
栏目：狂人读报
摘要：受邀参与，可能怎样改变当事人组织的构成、声音与自主性？

> **用词说明：** 本文的 **user** 是 *service user*（服务使用者）的简称，指正在使用或曾经使用相关服务的人，在这项研究中主要指精神卫生服务的使用者。
>
> 在西方精神健康运动中，尤其是英国的语境里，user 也是一个带着集体行动历史的称呼：当事人自己组织起来，开展互助、争取权利，并要求参与影响自身生活的服务与决策。因此，user 组织不只是医院里的“患者小组”，也可能是独立于服务机构、对其提出批评和要求的集体力量。
>
> **survivor**（幸存者）强调的则是“从什么之中幸存下来”：有人指精神痛苦或创伤，也有人明确指精神医学体系中的强制、伤害与压迫。
>
> 关于命名的政治，推荐阅读 Bonnie Burstow 的文章 [*A Rose by Any Other Name: Naming and the Battle against Psychiatry*](https://canadianscholars.ca/book/mad-matters-second-edition/)（收录于 *Mad Matters*），这里不多展开。
>
> 为了行文更通顺，避免反复出现较长的“服务使用者”，下文保留英文 **user**，不逐一翻译。例如，user 组织指这些人组成的组织，user 参与指他们参与服务的讨论、评估和决策等活动。下文引文中的相关称谓也作了统一；文末论文题名保留原译。


近些年，越来越多的医院、社区和服务机构开始说：我们要听亲历者的声音，要让当事人参与进来。邀请你去座谈、做培训、讲自己的故事、当同伴支持者，如果幸运的话，可能还会收获少量的报酬。很多亲历者因此第一次被认真对待，并且对精神卫生体系产生改观甚至感激。

但瑞典学者 Erik Eriksson好奇，这种让当事人参与进来的做法，会不会产生一些不那么好的影响？他用一年半的田野调查回答了这个问题。

## 一、背景

瑞典的精神卫生领域的 user 运动，起源于 20 世纪六七十年代。当时的精神科患者、囚犯、成瘾治疗服务的 user 各自成立组织，反对他们眼中"专断而家长主义"的福利实践，要求更多权力。"user 参与"这个想法最早就是这样来的：由独立的草根运动，从体制外部提出的政治要求。

后来国家采纳了这个概念。今天，user 参与在很大程度上已成为一个公共管理的概念，由瑞典福利体系从内部、自上而下地管理。user 参与的含义由此成为：邀请 user 参与体制、机构内部的评估、发展和质量管理。

作者把这两种含义分别称为"民主取向"（强调集体权利、分享权力、政策变革）和"管理主义取向"（强调提高效率、强调个人选择、内部质量改进）。


> **先说明两个容易产生歧义的词**
>
> 本文里的“机构”，主要指这项瑞典研究中的公共精神卫生服务机构，也就是掌握服务资源、专业权威和参与规则的医院及管理部门，不是泛指所有组织。联系中国语境来理解，我们还可以讨论更广义的“精神卫生建制”：它不只包括行政意义上的“体制内”单位，也包括依托既有医学权威、参与制定规则和分配机会的组织。例如，精神科医生创办的公益组织，即使登记为民间组织，也可能在某些合作关系中扮演建制一方的角色。判断的关键不只是它叫什么、在哪里登记，而是谁决定议题、分配资源，以及谁有权认可或否定他人的知识。不过，这是联系中国语境作出的延伸，不是对原文所有“机构”的统一替换。
>
> “运动”则指“社会运动”，在这里具体是 user 自己组织起来，通过互助、公共倡导和集体行动争取权利、推动改变。它不是我们国家语境下行政部门发起的“卫生运动”，也不只指街头抗议。例如，几个当事人小组互相联系，共同讨论强制治疗问题、形成诉求并要求服务方回应，就是这种集体行动的一种可能形式。下文会视具体意思使用“当事人组织”“民间行动”或“集体力量”。


## 二、一个关键概念：收编

作者借用社会学经典概念"收编"（co-optation）来分析。这个概念来自 Selznick 1949 年对美国田纳西河流域管理局的研究，定义是：

> 把新的要素吸纳进一个组织的领导层或政策决定结构，以此化解对该组织稳定或存续的威胁。

由于“收编”这个词听起来没有那么的善良，这里要特地说明两点：

第一，收编并不等于"坏人使坏"。它描述的是一个更有权势的组织把外部力量请进来，同时也取得对整个变革过程的控制，使之符合自身利益。

第二，被纳入的一方并非毫无空间，仍可能"从内部施加影响"。作者把这称作"获得允许的抵抗"：能抵抗，但在被允许的范围内。

他引用的另一位学者的话，大概是全文最精准的一句概括：

> 收编往往要求〔user〕组织去适应〔国家的〕要求与期待。例如，user 组织被当成一群了解自身处境的专家，而不是一股制衡力量或抗衡权力。

作为专家，虽然听起来不错，但是意见提完了之后，但哪些意见重要、是否落实，仍由邀请你的那一方来决定；而作为一股制衡力量，则意味着你不只依靠受邀发言来推动改变。即使意见没有被采纳，大家仍能依靠自己的组织继续讨论、公开表达，并争取其他支持，而不必把所有希望都放在下一次受邀上。


## 三、在看上去很棒的“user 参与”中，有什么悄悄的变了？

作者的研究对象是瑞典一家约有 3000 名员工的大型公共精神卫生机构。他跟踪了该机构自己界定为"user 参与"的活动，共 37 次观察，约 600 页田野笔记。他发现影响分两个方向。

### 影响一：运动的"构成"变了

**1. 有限的时间精力被抽走。** 在一次 user 委员会会议上，一位 user 组织代表马格努斯，对机构提议的大型联合培训项目表示担心：

> 我指的不是钱，是人。……就那么几个人，不可能坐在没完没了的理事会、委员会里，还参加〔精神卫生机构内部〕各种各样的其他项目。到头来，我们会失去自己的人。

机构代表当场承认："确实可能会把本来用于更独立、更具批判性的〔工作〕的精力抽走。"另一位代表接话："从那些我们想靠自己做成的事情上抽走。"

但最后，组织还是决定参加了。机构有资金、有场地、有员工，而民间运动只有有限的志愿者。

**2. 骨干被聘走了。** 机构把运动中的核心人物聘为内部员工。对本人来说，这往往是向前迈出的一大步，作者没有否认这一点。但同时，原本在运动中起凝聚作用的人，"现在实际上成了国家行政体系的雇员"。

**3. 机构可以绕过运动本身转而挑选个人。** 当机构想要的是"个人经历"而非"组织立场"，它完全可以自己挑人。一位工作人员说，他们有一个"代表库"，需要时直接联系。机构还付得起报酬，而民间运动通常只能指望成员做志愿者。

举个例子，假设有一个持有批判取向的精神健康民间组织，这里面的人都有一些反思的意识和对亲历者利益的关切。但有一些人只是希望服务质量能更提高一些，自己本人所遭遇的伤害没有那么大，甚至并没有遭遇过伤害，ta愿意参与这些反思只是出于一种智识和道德上的追求；还有一些人经历了医疗事故，终身都受到影响，对于医院抱有深深的不信任，ta参与这个组织是切实希望推动问责、推动结构改变。这个时候，医院完全可以展示出自己亲和的一面和进步的姿态去邀请前者，而直接跳过这个组织，也更不可能邀请后者。而前者也会觉得医院还不错，和医院双向奔赴，同时觉得自己组织里的其他志愿者“太极端了”，觉得自己所在组织的目标“太不现实了”。

论文里有一段很有意思的田野笔记。一位不属于任何组织的 user，常被邀请去讲自己的就医经历。她担心保不住本职工作，于是考虑：

> 如果丢了工作，她在考虑自己创业，承接精神卫生机构的委托，像这样讲授 user 视角，加入 user 参与的工作。她听别人说，讲课、把自己的经历写成书，收入可以相当不错。

作者由此指出一种"个体化"甚至"商品化"的趋向：人们不必加入运动，可以直接向机构"出售"自己的亲身经验。他还观察到一个倾向：**和运动没有联系的参与者，较少提出批评，行动方式更贴近机构自身的理路。**



### 影响二：运动的声音被改变了
当 user 被邀请加入机构的培训会议时，他们可能在不知不觉中就被改变了。虽然口号上说的是服务和研究要纳入当事人的声音，但最后，这种纳入有可能变成体制对体制外单向的改变。

**1. 被教会"怎么发言"。**

一位机构高层回忆他刚上任时与 user 组织开会：

> 感觉像回到了 1970 年代。尽是争论和对抗，指责在屋里飞来飞去。……但从那以后，我觉得我们找到了建设性地处理 user 参与问题的办法。

他还讲到，机构为新加入的 user 代表办两天的"沟通培训"，负责人用这样一句话结束课程：

> 如果有一件事最要紧，不管你在外面遇到什么场合、同什么人说话，那就是：'做个好榜样！'还有，'着重讲什么帮助过你！'

**2. 被引导"谈什么问题"。** 有一次，会议讨论一份批评该机构的外部审计报告，报告指出了四个需要改进的方面，运动平时也都批评过。主持会议的管理者先发言十五分钟，只认可其中一项，另外三项逐一"说明审计有误"。接下来整整三十分钟，大家只讨论那一项，没有人再提另外三项。结束时他说：

> 真要再谈的话，就集中谈这一项，记录这一项。因为其他三项我们都会为自己辩护。

**3. 被要求"现实一点"。** 在一次分组讨论中，主持人对运动代表说："记住建议要可行，这正是主管们能帮得上忙的地方。" 谁来判断什么"现实"？是机构、是制度。

最后，连运动代表自己也开始这样做。一位有经验的代表在小组里说，如果把目标定得太高，很可能什么都办不成，于是大家没有去选*最重要*的改变，而是只选"改得动"的。作者评论说，这个限制是他从以往参与机构活动中学来的，现在又由他在 user 小组内部实行自我规训。

作者借用另一项研究的话总结：运动"关于正义的梦想，关于和平的梦想"被大幅缩减，取而代之的是更有限的目标。

### 把这一切包起来的，是"共识话语"

这些事为什么很难被察觉？因为整个过程被一层温暖的话语包裹着。会议开场，机构负责人许多次用到"我们"，"张开双臂，示意'我们'指的是专业精神卫生体系与 user 运动双方"。他说，他相信有许多大家都能达成一致的"共同利益"。

维克托曾问过一个关键问题：在联合项目里，我们的看法会怎么表达出来？机构代表答得很坦率："这个项目的目的不是呈现 user 组织对社会或瑞典精神卫生体系中存在的问题的解读……但它不是要做 user 运动的传声筒。"

维克托接着追问："那它也不是精神卫生机构的传声筒吧？" 对方说："不是。它是什么呢……就是一个个具体的人的经历。"

**集体的、批判性的声音，就这样被转换成了各种各样的个人故事。** 而"相互理解""共同目标"这些词，让人不愿提出会威胁气氛的批评。

作者的核心论点是：

> 公共服务的 user 参与的实践，可能损害 user 在公民社会中自主进行动员、组织和行动的能力；而围绕参与的正面共识话语，既遮蔽这一事实，也为这种损害的发生创造了条件。






## 五、结语

坦率地说：瑞典有深厚的社团主义传统、成熟的志愿部门和政府与运动之间的正式协议(注：简单说，政府不是只听取零散个人的意见，而是长期与代表不同群体的组织协商，让这些组织参与政策制定，有时也参与执行和监督。 这种制度化安排，就是这里说的“社团主义”（corporatism）。例如，工会代表劳动者、雇主协会代表企业，与政府协商有关政策。瑞典历史上，一些利益团体还在政府部门的委员会中拥有正式席位，部分能够参与决策。) 中国的情况在制度、历史和语境上都很不同。但这篇论文描述的机制，并不依赖瑞典特有的制度。它依赖的是一个朴素的事实：**邀请的一方有资源、有场地、有决定权，被邀请的一方通常是志愿者，时间和人手有限。** 这种不对称在很多地方都存在。

分享这篇文章，并非在劝阻大家参与相关的活动或推动相关的事业，而是作为一种提醒，让我们思考哪些改变可能发生，哪一些东西可能会消失。其实，整个文章所说的负面影响，大多数时候都是“无意间”发生的，因此很难去批评个人的志向，但跳出来感受整体结构如何运转仍然有必要。收编这个词听起来虽然听起来颇有落了下风的味道，但被收编的一方仍然可以在关系内部施加影响，只是这种影响能到什么程度，在多大程度上被纳入的那一方还能维持自觉，恐怕只有身处其中的人心知肚明了。

老实说，我也觉得被邀请听起来总是让人心里很舒服的。想起来以前知乎平台很活跃的时候，人们也喜欢说“谢邀”。可是那么多答案，活跃地去说“谢邀”的，往往是心理学的专家或精神病学的专家，我们又有几次见到过亲历者获得最高赞的。亲历者，在很多时候并不受这个社会欢迎，也并不受那个治疗和管理他们的系统欢迎。很多人在邀请亲历者的活动里，第一次觉得自己的痛苦和经验没有白费，可以变成对别人有用的东西。这份感受值得被认真对待。

也正因为这样，这篇论文的提醒才显得不容易说出口。因为收编之所以有效，恰恰不靠强迫，而靠这份真实的好意和真实的渴望。在论文的田野里，没有谁被威胁，也没有谁被禁言。机构负责人说"我们"的时候，眼神是诚恳的；培训老师说"做个好榜样"的时候，多半也是出于善意。

而拒绝，在这样的处境里代价极高。

抵抗和拒绝总是令人疲惫且孤独的。你拒绝一次邀请，可能意味着失去一个难得的发声机会；你坚持说出批评，可能让会议气氛变得尴尬，下次就不再被请。你的同伴里有人已经在体系里拿到了职位和报酬，他们会说"先进去，才能从内部改变"，这话有时是对的，有时也是一种自我安慰。比起"接受邀请"这条省力的路，"保持距离"需要的是一份更持久的力气，而亲历者本来活下去已经不易，要有这份力气又谈何容易？

接受邀请或不接受邀请，去或者不去，我想都可以，只是希望亲历者自身的信心和勇气，从来不取决于他者的点头。点头是对方的事，价值是自己的事。

论文引用过一句话，形容机构理想中的 user："active but not activist’ manner（出力可以，出头不行）" 这句话听起来很温和，却值得所有亲历者记住：**当有人欢迎你来，却又希望你别太尖锐的时候，欢迎本身，可能就已经带着条件了。**
